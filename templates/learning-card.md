# 模板：工程知识沉淀卡片 (Learning Card Templates)
> 适用于 Obsidian (支持 Callout & 双链)、Notion、Logseq 或普通 Markdown 笔记库。

---

## 选项 1：Obsidian 原生 Callout 双链版 (推荐 ⭐)

```markdown
> [!NOTE] 工程心智模型 (Mental Model) #架构设计 #{{技术栈标签}}
> - **任务定位**：{{ 一句话说明本次解决的工程问题 }}
> - **底层逻辑**：{{ 改动前 vs 改动后的核心设计转变 }}
> - **核心模式**：[[{{ 依赖注入 / 状态机 / 幂等性设计 }}]]
> - **避坑法则**：{{ 下次遇到类似场景的黄金法则 }}
> - **涉及链路**：`{{ path/to/caller }}` → `{{ path/to/changed_file }}` → `{{ path/to/callee }}`

> [!TIP] 核心术语速查 (Glossary)
> - **[[{{ 术语名称 }}]]**：{{ 通俗生活类比 }}（在源码第 `{{ 行号 }}` 行体现）

> [!QUESTION] 抗偏置巩固自测 (Quiz)
> 1. **{{ 行为预测 / 代码找茬 / 场景思考题 }}**
> <details>
> <summary>💡 查看思考提示与解析</summary>
> 
> > **思考引导 (Hint)**：{{ 关键变量或生命周期线索 }}
> > 
> > **参考答案与解析**：{{ 深入剖析原因与避坑要点 }}
> </details>
```

## 选项 2：Notion 模块结构版 (Notion Blocks)

```markdown
### 🧠 工程心智模型: {{ 任务名称 }}
- **问题分类**: `{{ #Bug修复 / #架构重构 / #新功能 }}`
- **技术栈**: `{{ #Vue3 / #TypeScript / #Spring / ... }}`

| 维度 | 改动前 (Before) | 改动后 (After) |
| :--- | :--- | :--- |
| **设计逻辑** | {{ 紧耦合 / 易竞态 / 缺乏防御 }} | {{ 接口解耦 / 确定性状态机 / 幂等校验 }} |
| **代码位置** | `{{ path/to/old }}` | `{{ path/to/new }}` |

> 💡 **黄金避坑法则**：{{ 一句话经验总结 }}

### 📚 核心概念提取
- **概念**: `{{ 术语 }}` — {{ 白话比喻 }}
- **代码映射**: `{{ 文件名:行号 }}`
```
